# Python-File-Handling-And-Data-Management
Description

A Python project developed for my Computer Science coursework at Howard University. This project demonstrates file handling, text processing, and data management through speech file processing, astronaut name lists, and student record manipulation.

Projects

1. Bill Clinton Speech Files

- Opens and reads two speech files.
- Combines the contents into a new file.
- Writes and saves an important sentence to a separate text file.
- Counts and prints the number of lines in the combined speech file.





2. Black Astronauts

- Reads and combines three files containing names of Black astronauts.
- Prints each astronaut's name on a separate line.
- Removes Leland Melvin from the combined list and saves the updated list to a new file.
- Uses file management operations to delete and rename files.





3. Student Records

- Reads and displays student records with tab-separated fields.
- Appends a new student record for Madison Gardner.
- Updates the graduation year of the Engineering student from 2025 to 2024.
- Prints the updated student records.



Technologies Used

- Python
- IDLE (Python Editor)



Skills Demonstrated

- File input and output
- Reading, writing, and appending files
- Text processing and string manipulation
- File merging and line counting
- File deletion and renaming
- Data organization and record updates
- Loops and iteration
- Working with text files

Repository Structure

- bill_clinton_speech.py — Processes and combines speech files.
- blackastronaut.py — Combines astronaut lists and manages files.
- student_records.py — Reads, appends, and updates student records.
- README.md — Project documentation.

How to Run

- Download or clone this repository.
- Ensure the required input text files are in the same directory as the Python scripts.
- Open a script in IDLE or another Python environment.
- Run each script individually.
- Review the printed output and generated text files.

Academic Context

Developed as part of Computer Science coursework at Howard University to practice Python file handling and data management
